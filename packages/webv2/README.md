# eKYC Web Application

React 18 TypeScript frontend for the eKYC identity verification system, built with the AWS Cloudscape Design System.

## Key Technologies

- **React 18** with TypeScript
- **Cloudscape Design System** -- AWS UI component library
- **AWS Amplify** -- authentication and backend integration
- **@aws-amplify/ui-react-liveness** -- face liveness verification
- **React Query** (@tanstack/react-query) -- server state management
- **Axios** -- HTTP requests
- **React Router** -- client-side routing

## Features

- **Verification Wizard** -- guided multi-step identity verification flow
- **Document Upload** -- upload and extract field data from identity documents
- **Liveness Check** -- real-time face liveness verification with facial comparison
- **Verification History** -- browse previous verification attempts
- **Training Jobs** -- create and manage model training jobs
- **Settings** -- application configuration

## Development

### Prerequisites

The app reads Amplify configuration generated by the `PostDeploymentScripts` package after CDK deployment. Run the full deployment pipeline before starting local development.

### Commands

```bash
pnpm install       # Install dependencies
pnpm start         # Start dev server on port 3000
pnpm run build     # Create production build
pnpm test          # Run tests
```

## Authentication

Uses Amazon Cognito via AWS Amplify. Users must sign in before accessing the application.
